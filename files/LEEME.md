# Carpeta de archivos de Violet

Todo lo que pongas en esta carpeta (o en subcarpetas) aparece automáticamente en la web
con su botón **Descargar**. Este archivo `LEEME.md` no se publica.

- Subir: **Add file → Upload files** (máx. 25 MB por archivo desde la web de GitHub; 100 MB con git).
- Borrar: abre el archivo → menú **···** → **Delete file**.
- Nombre bonito y descripción: edita `catalogo.json` en la raíz del repositorio.
